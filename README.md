## 📱 TUTORIAL DE INSTALACIÓN (ANDROID)

### Paso 1: Descargar y extraer
<details>
<summary><b>⬇️ Haz clic para ver</b></summary>

- Descarga el archivo `.zip` desde este repositorio.
- Usa cualquier gestor de archivos y **extrae** (descomprime) el contenido en una carpeta.
  1. Descomprime el archivo: **Gen2Recomped.apk.zip** alli encontraras el apk del emulador 3D: Gen2Recomped.apk
  2. NO EXTRAER O DESCOMPRIMIR EL ARCHIVO: **GRAFICOS 3D.zip** (el apk Gen2Recomped.apk lo reconoce en formato zip
  3. Descomprime la carpeta **GAMEBOY - POKEMON - r0ms**
</details>

### Paso 2: Activar "Orígenes desconocidos"
<details>
<summary><b>⚙️ Haz clic para ver el minitutorial</b></summary>

1. Ve a **Ajustes** del dispositivo.
2. Entra en **Seguridad** o **Biometría y seguridad**.
3. Busca **"Instalar aplicaciones de orígenes desconocidos"**.
4. Selecciona la app que usas para instalar (ej. *Files* o *Chrome*).
5. Activa el permiso a **ON**.
</details>

### Paso 3: Instalar las APK
<details>
<summary><b>📲 Haz clic para ver</b></summary>

- Ve a la carpeta donde extrajiste el `.zip`.
- Toca `M* B*y.apk` → pulsa **Instalar**.
- Toca `G*N2 R*C*MP*D.apk` → pulsa **Instalar**.
</details>

### Paso 4: Cargar las R*ms
<details>
<summary><b>🎮 Haz clic para ver</b></summary>

**Para M* B*y (2D):**
- Abre la app → toca el ícono 📂 de abrir archivo.
- Navega a `GAMEBOY/P*KEMON/r0ms/`.
- Selecciona tu R*m y juega.

**Para G*N2 R*C*MP*D (3D):**
- Abre la app → toca **"Load Game"** o **"Select Directory"**.
- Ve a la misma carpeta `GAMEBOY/P*KEMON/r0ms/`.
- Elige la R*m y espera a que carguen las texturas 3D.
</details>
